# Cashfree

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Collections agents using a daily workspace to review outstanding loans, prioritize borrower follow-ups, and log calls. The user confirmed this audience and full-workspace scope.

## Product Purpose
Keep borrower records, loan balances, and agent interactions together so agents can act with the right context.

## Capabilities and Constraints
React, TypeScript, Vite, Tailwind CSS. Preserve borrower search/filter/sort, table and card views, call filtering, customer and interaction details, new-record forms, transcripts, audio, theme switching, and Supabase setup. Supabase uses customers and agent tables; demo records persist in localStorage. Existing data is denominated in USD. No authentication, real calling, payments processing, or historical reporting backend exists.

## Brand Commitments
Cashfree is the product name. The user requested a full UI/UX redesign using Impeccable. No palette or logo specification was supplied.

## Evidence on Hand
README.md, src/types/database.ts, src/lib/supabaseClient.ts, src/data/mockData.ts. Six sample borrowers and six sample interactions; sample dates are historical. Never invent live activity or financial trends.
